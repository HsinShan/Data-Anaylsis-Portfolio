# 自製研究: 2025/04 台灣數據就業市場洞察

Period: 2025.04 自製研究

## Background

- 數據職缺類型多元，企業對職位定義不一致，內容界線模糊
- 技能需求範圍廣泛，缺乏標準化，求職者難以精準定位與規劃
- 市場缺少系統性整理，無法有效對應技能與薪資發展

## Objective

1. 分類職缺內容以了解市場需求
2. 找出提高薪資的關鍵技能組合
3. 探討其他影響薪資的因素

## Methodlogy

1. 資料蒐集: 使用 Python 爬取 104 職缺內容，取得 6736 筆職缺，經過前處理後保留 1954 筆進行分析
2. 職缺內容文本處理: 中文使用 jieba 斷詞，英文使用 spaCy 處理，建立自定義數據工作相關詞彙字典
3. 職缺分類: 使用 LDA 主題模型將職缺分為 BA、DA、DS、DE、MLE 五大類
4. 薪資分析: 分析各職類薪資差異及影響因素，找出提高薪資的技能組合

## Result

### 🔍 各數據職類主題關鍵詞小結（LDA 主題模型分析）

透過 LDA 主題模型分析後，我將數據職缺分為五大類別，並歸納出各職位常見的技能與語意重點如下：

#### BA（Business Analyst）: 以「商業理解與流程優化」為主軸

強調報表製作、跨部門溝通與策略分析能力
關鍵詞：管理、流程、報表、策略、成效、解決方案、統計、溝通

#### DA（Data Analyst）: 偏向「數據洞察與決策支援」

著重資料分析、洞察生成與優化建議
關鍵詞：數據分析、洞察、策略、建議、模型、決策、報告、溝通、統計

#### DS（Data Scientist）: 聚焦於「機器學習應用與商業價值轉化」

強調 AI 模型建立與跨部門協作
關鍵詞：AI、機器學習、分析、模型、成效、解決方案、合作、商業

#### DE（Data Engineer）: 強調「資料系統建置與維運」

涵蓋 ETL 流程、資料庫架構與雲端整合
關鍵詞：ETL、資料庫、SQL、開發、架構、雲端、維運、Python、資料倉儲

#### MLE（Machine Learning Engineer）: 核心在於「模型開發與部署工程化」

涵蓋深度學習框架與系統部署技術
關鍵詞：機器學習、AI、深度學習、模型、部署、訓練、LLM、TensorFlow、Pytorch、生成式 AI

### 🔍 各數據職缺類別薪資分析

#### 1. 技術類技能（如機器學習、深度學習、ETL 等）及策略相關能力對薪資具有顯著正向影響

DS 薪資最高，工程導向職缺(DE 及 MLE) 的薪資水平次之

#### 2. 工程導向的職位，年資對薪資有穩定正向的影響

#### 3. 非工程導向職位: 技術 + 商業具備薪資優勢

- 程式能力、機器學習技能及解決問題的能力對薪資有正向影響，但報告產出、分析、視覺化等操作性技能呈現負向影響，對提高薪資談判力無助益
- 根據關聯規則，統計+機器學習或策略+機器學習高薪機率高，因此具備跨領域技能較有薪資優勢

#### 4. 迴歸分析顯示，企業在給出高薪的考量上，較看重跨域能力與策略+技術的組合

遠端工作+工程背景、碩士學歷+溝通能力等組合能為人才帶來每月+40K~+60K 的薪資提升
若技能過於單一或過度偏工具操作（如 martech、單獨 AI），反而會壓抑企業的開價意願，可能使薪資上限下降 10K~14K

### 結論

台灣數據職缺市場中，DS 職位在薪資水平上領先，而 ML 和 DE 職位則具有較好的薪資成長性  
技術類技能（如 Git、機器學習、ETL 等）對薪資有顯著正向影響，特別是在工程導向職缺中效果明顯  
非工程類職能職涯路線建議:

1. 發展跨域能力:技術+商業思維的組合最具價值
2. 提升學歷與溝通力: 碩士+溝通能力多為主管職的所需技能
3. 強化技術深度: Python、機器學習、ETL 等技能有顯著加分效果
4. 避免單一工具型技能: 純操作性技能難以提升薪資上限
